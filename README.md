# Recap — stato della cartella

Aggiornato al 23/09/2026.

Raccolta di esercizi e ripassi Python, non un progetto unico. Venv proprio
(`.venv`) e file `.env` presenti. Nessun repository git.

## Contenuto

- **udemy_track01_astronave_andromeda** — design pattern applicati a un caso
  d'esempio: `factory`, `observer`, `state`, `composite`, grafi e un
  `centralComputer`. È la parte più strutturata, con `classes/` e `docs/`.
- **udemy_track02_rabbitmq** — producer, consumer e script di avvio di RabbitMQ.
- **udemy_track03_mongodb** — MongoDB in Docker Compose, con script di
  inizializzazione e un `main.py`.
- **udemy_track04_openai** — un singolo `main.py`, appena iniziato.
- **mini_progetti** — esercizi sparsi: classi, conto corrente, file, pattern
  matching, slots, una cartella `rpg` e appunti.
- **minigioco** — piccolo gioco con `main.py`, `entities.py`, `settings.py`.

## Stato

Materiale di studio completato o in corso, senza versionamento e senza
dipendenze dichiarate in un requirements. Il valore è didattico: non c'è niente
da mettere in produzione.

## Prossimi passi possibili

- Un `requirements.txt` per rendere riproducibile il venv.
- Portare la cartella sotto git se vale la pena conservarne la storia.
